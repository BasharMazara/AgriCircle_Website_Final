# AgriCircle Website - HTML5 & CSS3 Project

## Project Overview
AgriCircle is a fully functional website built with HTML5 and CSS3, designed as an agricultural community platform. The website demonstrates modern web development practices, semantic HTML structure, responsive design, and professional styling.

## Features Implemented

### 🌐 **10+ Complete Pages**
1. **Home** (`index.html`) - Landing page with hero section and community overview
2. **About** (`about.html`) - Mission, vision, and company information
3. **Contact** (`contect.html`) - Contact form and company details
4. **Services** (`services.html`) - Comprehensive service offerings
5. **Portfolio** (`portfolio.html`) - Project showcases and achievements
6. **Album** (`album.html`) - Photo gallery and community highlights
7. **Privacy Policy** (`privacyPolicy.html`) - Data protection policies
8. **Return Policy** (`returnPolicy.html`) - Service return guidelines
9. **Terms and Conditions** (`TermsandConditions.html`) - Legal terms
10. **Blog** (`blog.html`) - Articles and insights

### 🏗️ **HTML5 Semantic Structure**
- `<header>` with logo and navigation
- `<nav>` for main menu system
- `<main>` for primary content areas
- `<section>` for content groupings
- `<article>` for individual content pieces
- `<aside>` for sidebar content
- `<footer>` with contact information
- Proper heading hierarchy (h1-h6)
- Semantic lists, tables, and forms

### 🎨 **CSS3 Styling & Design**
- **Responsive Design**: Mobile-first approach with flexible layouts
- **CSS Grid & Flexbox**: Modern layout techniques
- **Color Scheme**: Professional green agricultural theme
- **Typography**: Readable font hierarchy and spacing
- **Animations**: Hover effects and smooth transitions
- **Cards Layout**: Modern card-based content organization

### 🧭 **Navigation & Usability**
- Consistent navigation menu across all pages
- Responsive navigation for mobile devices
- Internal linking between related pages
- Clear call-to-action buttons
- User-friendly URL structure

### 📝 **Forms & Functionality**
- **Contact Form** with validation
  - Name, Email, City, Subject, Message fields
  - Required field indicators
  - Send and Clear buttons
- Proper form labels and accessibility

### 🖼️ **Multimedia Elements**
- **Logo**: Professional AgriCircle branding
- **Hero Images**: High-quality agricultural photography
- **Gallery Images**: Community and farming photos
- **Responsive Images**: Adaptive sizing for all devices
